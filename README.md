# Exercício 7 — Algoritmos em Java

Programa de console que lê os dados de 10 pessoas e calcula:
- quantas têm mais de 50 anos;
- a média das alturas de quem tem entre 10 e 20 anos;
- a porcentagem de pessoas com peso abaixo de 40 kg.

## Como executar

É necessário ter o Java instalado. No terminal, dentro da pasta do projeto:

```bash
javac Exer7.java
java Exer7
```

Para cada pessoa, informe a idade, o peso em quilogramas e a altura em metros.
